## 会话 6（20:45，非确定性排查——两个真 bug 修复）

- **Bug 1（save 崩溃）**：save/restore 的 checkpoint rec 槽索引 `2*is+kv2` 中 is 按 kv2 迭代计数
  （应按层计数）→ 索引 0,2,4,...,18 越界 10 槽 vector → OOB 读（垃圾 Buffer 过了 `!dst` 检查 →
  setBuffer SIGSEGV）+ OOB 写（堆破坏 → 间歇 Invalid Resource）。
- **Bug 2（非确定性）**：逐层探针（LFM3_X_PROBE）钉住首个分歧层 = 第一个 SWA 层。qk_prep 网格覆盖
  整个 chunk（≤2048 行）而滑窗缓存是 264 槽环 → 位置 p 与 p+264 同一 dispatch 写同一槽，胜者不定 →
  末行窗口读到输家的数据 → logits 每轮漂移。修复：槽只由 chunk 内最新位置写（pos+cap ≥ pos0+T）。
- 证据：探针 25/25 槽跨进程 bitwise；两份全量 dump（8 窗 192 行）prefill+step 全 bitwise；
  floor repeat = 8/8 + 192/192 bitwise KL 0（原 0/192）；gate top-1 ≥ 0.8125；harness + CPU + 门禁
  全绿；serve 稳定。提交 037f089f，已推 lfm3-pr2，PR #1 已更新。
- 方法论收获：**确定性二分链条**——内核层跨进程确定（chain ao[0] 三轮一致）→ 模型层不定 → 逐层
  探针定位层 → 层内结构审查找唯一非行局部的写。floor 的 repeat 源就是为此设计的回归测试。
- 陷阱：logit_dump 自己会拿 GPU 锁，外面再套 lockf 会自等待死锁（20 分钟）。
- 待办：3/3 PR（等 1+2 合并）；修复后路径的 HF fp32 新对照（旧 81.25% 测在有竞态的路径上，只会更近）；
